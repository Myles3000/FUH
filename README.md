Target Device:
We will only be using the provided controller as well as our personal android devices

Github Link: Myles3000/FUH

Interaction techniques:
Movement will be gait negation and only be accessible through the controller
All interactions are done from the controller. The user will navigate to the start button in the start scene and click the “OK” button. Once pressed, they will be navigated to the Apartment. When the player wants to travel back in time, they will use the controller to move to the tv and click “OK” to be transported back to the Han Dynasty. They can then use the controller to explore the scene. 
The “OK” button is mapped to the corresponding click read by Android
